A. True Dynamic Cumulative VWAP (વોલ્યુમ વેઈટેડ એવરેજ પ્રાઈસ)

જૂના વર્ઝનમાં સાદો મિડ-પોઈન્ટ લેવાતો હતો જે કેન્ડલની અંદર ચોંટેલો રહેતો હતો. V2 માં ટ્રુ ક્યુમ્યુલેટિવ VWAP લોજિક લાગુ કરાયું:

Typical Price (TP_i) = (High_i + Low_i + Close_i) / 3
VWAP_t = Σ (TP_i × Volume_i) / Σ (Volume_i)

B. Dynamic Standard Deviation Bands (Value Area High & Low)

VWAP ની આસપાસ વોલેટિલિટી આધારિત બે સ્ટાન્ડર્ડ ડેવિએશન બેન્ડ્સ બનાવવામાં આવ્યા:

  • 🟠 Upper Band (+1.0 / +1.28 StdDev) - Value Area High (VAH): ઓવરબોટ ઝોન / ઇન્સ્ટિટ્યુશનલ રેઝિસ્ટન્સ.
  • 🔵 Lower Band (-1.0 / -1.28 StdDev) - Value Area Low (VAL): ઓવરસોલ્ડ ઝોન / ઇન્સ્ટિટ્યુશનલ સપોર્ટ.
  • Mean Reversion Logic: જ્યારે પણ ભાવ બેન્ડ્સની બહાર ફેંકાય છે ત્યારે તે ચુંબકીય આકર્ષણ (Magnetic Pull) થી પાછો પીળી લાઈન (VWAP) તરફ ખેંચાઈ આવે છે.

A. Bill Dreiss Choppiness Index (CHOP) - સાઇડવેઝ ડિટેક્ટર

માર્કેટ ટ્રેન્ડમાં છે કે સાઇડવેઝ કન્સોલિડેશનમાં તે શોધવા માટે 14-પીરિયડ ફ્રેક્ટલ ડાયમેન્શન ઇન્ડેક્સ લાગુ કર્યો:

CHOP = 100 × [ log10( Σ ATR_1(i) / (MaxHigh_14 - MinLow_14) ) ] / log10(14)
  • CHOP ≥ 60.0: માર્કેટ અત્યંત ચોપી/સાઇડવેઝ છે. સિસ્ટમ ઓટોમેટિકલી ટ્રેડિંગ બ્લોક કરે છે અને ચેતવણી આપે છે: ⚠️ SIDEWAYS CHOPPY (TRADING BLOCKED).
  • CHOP < 38.2: મજબૂત વિસ્ફોટક ટ્રેન્ડ શરૂ થઈ ગયો છે.

B. Kaufman Efficiency Ratio (KER) - ટ્રેન્ડ નોઇઝ ફિલ્ટર

KER = | Close_t - Close_{t-n} | / Σ | Close_i - Close_{i-1} |
  • KER < 0.25: માર્કેટમાં ફક્ત નોઇઝ છે, કોઈ દિશા નથી. ટ્રેડિંગ પ્રતિબંધિત.
  • KER ≥ 0.60: સુપર સ્મૂથ ઇન્સ્ટિટ્યુશનલ ડાયરેક્શનલ મુવ.
